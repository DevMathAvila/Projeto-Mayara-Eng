# Mayara Gaspareto | Arquitetura & Engenharia

> Portfólio digital de alto padrão desenvolvido para a profissional Mayara Gaspareto, unindo a precisão da engenharia com a estética da arquitetura contemporânea.

---

## 🏛️ Sobre o Projeto

Este projeto foi concebido para ser mais do que um portfólio; é uma ferramenta de branding e captação de clientes para o escritório sediado em Indaiatuba. O foco principal foi criar uma experiência de usuário (UX) fluida, com carregamento instantâneo e design responsivo que reflita a sofisticação das obras realizadas.

### Por que este projeto existe?
* **Autoridade Digital:** Estabelecer uma presença profissional sólida no mercado de Indaiatuba e região.
* **Performance:** Substituição de bibliotecas pesadas por soluções nativas para garantir que o cliente não desista do acesso por lentidão.
* **SEO Local:** Otimização para mecanismos de busca focado em termos como "Arquitetura Indaiatuba" e "Engenharia de Precisão".

---

## 🛠️ Tecnologias Utilizadas

O projeto utiliza o que há de mais moderno no ecossistema de desenvolvimento web:

* **Next.js 15 (App Router):** Framework principal para renderização rápida e SEO otimizado.
* **Tailwind CSS:** Para estilização baseada em utilitários, garantindo um código limpo e responsivo.
* **Framer Motion:** Responsável pelas animações sutis e elegantes (Reveal effects).
* **Lucide React:** Conjunto de ícones minimalistas.
* **React Hook Form:** Para gerenciamento eficiente de formulários (se aplicável).
* **JavaScript/ES6+:** Lógica de programação moderna.

---

## 💎 Diferenciais Técnicos

1.  **Glassmorphism Navbar:** Menu flutuante com efeito de vidro jateado e desfoque de fundo (backdrop-blur).
2.  **Performance Otimizada:** Implementação de `prefetch` nos links e carregamento prioritário de imagens (`Next Image`).
3.  **Jornada do Cliente:** Seção estratégica que guia o lead através das etapas de Briefing, 3D, Aprovação e Execução.
4.  **Metadados Avançados:** Configuração completa de SEO, incluindo OpenGraph para compartilhamento profissional em redes sociais e WhatsApp.

## 🚀 Como rodar o projeto localmente

1.  Clone o repositório:
    ```bash
    git clone [https://github.com/SeuUsuario/Projeto-Mayara-Eng.git](https://github.com/SeuUsuario/Projeto-Mayara-Eng.git)
    ```
2.  Acesse a pasta:
    ```bash
    cd Projeto-Mayara-Eng
    ```
3.  Instale as dependências:
    ```bash
    npm install
    ```
4.  Inicie o servidor de desenvolvimento:
    ```bash
    npm run dev
    ```
